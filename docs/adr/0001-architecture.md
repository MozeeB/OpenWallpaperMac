# ADR 0001: Native Swift, SwiftPM modules, thin app shell

**Status:** accepted

## Decision

- Swift 6 (strict concurrency, typed throws), macOS 15+, Apple silicon first.
- All logic in a local SwiftPM package split by domain (`OWCore`, `OWFormats`, `OWDesktop`,
  `OWRendering`, `OWScene`, `OWPower`, `OWAudio*`, `OWLibrary`, `OWAppFeature`); the Xcode app target
  (generated by XcodeGen from `project.yml`) only wires the SwiftUI scenes.
- Desktop windows in AppKit (SwiftUI windows cannot sit at the desktop level); UI in SwiftUI.
- Renderers: AVFoundation (video), WebKit (web), Metal (shaders, scenes). No Electron/Chromium/Qt.
- Immutable value models; state changes go through `AppModel.commit`, persisted atomically as JSON with
  tolerant decoding for forward compatibility.

## Consequences

`swift test` runs everything headless (including Metal, WebKit and AVFoundation integration tests).
`.xcodeproj` is generated and not committed.
